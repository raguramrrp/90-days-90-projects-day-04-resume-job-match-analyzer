# Data Assets & Skill Taxonomy Directory

This directory contains resources used by the **AI-Powered Resume–Job Description Compatibility Analyzer**.

## Contents

- `skills_taxonomy.json`: Comprehensive curated taxonomy covering 8 primary industry categories (Programming Languages, AI/ML & Data Science, Web & App Frameworks, Cloud & DevOps, Databases, Software Engineering & Tools, Soft Skills, and Certifications) along with alias mapping (e.g. `k8s` -> `Kubernetes`, `sklearn` -> `scikit-learn`).
- `sample_resumes/`: Realistic benchmark resumes across different technical profiles (AI/Data Scientist, Full-Stack Engineer, Junior Developer) formatted as `.pdf`, `.docx`, and `.txt`.
- `sample_jds/`: Real-world job descriptions representing modern roles (Senior AI/Data Scientist, Full-Stack Software Engineer, Cloud/DevOps Engineer).
